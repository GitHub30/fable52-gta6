# VELA BAY — Open World Sandbox

**▶ ブラウザで遊ぶ: https://github30.github.io/fable52-gta6/**

ブラウザ（Chrome デスクトップ）で動く、オリジナルの 3D オープンワールド・サンドボックスゲームです。
架空の島の都市「ベラ・ベイ」を徒歩と車で自由に探索し、ミッションをこなし、警察から逃げ回れます。
アセットファイルは一切なく、都市・車・人物・音はすべてコードから生成しています。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー（ポート 5173） |
| `npm run typecheck` | TypeScript 型チェック |
| `npm run build` | 型チェック + 本番ビルド（`dist/`） |
| `npm run preview` | ビルド結果のプレビュー |

## 操作方法

| 操作 | キー |
|---|---|
| 移動 / アクセル・ブレーキ・ハンドル | W A S D |
| カメラ | マウス（クリックでポインターロック。ロックできない環境ではドラッグ） |
| 走る | Shift |
| ジャンプ / ハンドブレーキ（運転中） | Space |
| 車に乗る・降りる（走行中の車は強奪） | E |
| ミッション開始・攻撃（パンチ / 射撃） | F / 左クリック |
| 武器切替（素手 / ピストル） | 1 / 2 |
| クラクション | H |
| ラジオ ON/OFF（運転中に再生） | R |
| ミッション中止 | M |
| 時間を 1 時間進める / 天候切替 | T / Y |
| 一時停止・操作確認 | ESC / P |

操作一覧はタイトル画面とポーズ画面でも確認できます。

## ゲーム内容

- **都市**: 12×12 ブロック（約 930m 四方）の島。ダウンタウン、商業区、住宅街、工業地帯、ビーチ、公園の 6 地区。
- **車**: セダン / スポーツカー / バン / タクシー / パトカー。駐車車両にも走行中の車にも乗れます。車にはダメージがあり、壊れると煙が出て動かなくなります。
- **街の動き**: 信号を守って走る一般車両、歩道を歩き横断する歩行者。危険を感じると逃げます。
- **手配度（★1〜5）**: 車両強盗・暴行・ひき逃げ・パトカーへの衝突で上昇。パトカーが追跡し、囲まれて止まると逮捕（BUSTED）。警察の視界から外れ続けると解除されます。
- **戦闘**: 素手とピストル。最初からピストル（36 発）を持っています。オレンジの弾薬箱で弾を補給、赤い救急キットで回復（どちらも 90 秒で再出現）。気の強い通行人は殴り返してきます。
- **徒歩の警官**: ★2 以上で、止まったパトカーから警官が降りて追ってきます。至近距離で逮捕、★3 以上では発砲。倒すと弾を落としますが手配度が上がります。空になったパトカーは奪えます。
- **ミッション（5 種）**: ミニマップのピンクの◆へ徒歩で行き F で開始。配達、チェックポイントレース、逃走、タクシー、木箱回収。クリアで賞金。
- **イベント・収集**: ランダムに出現する現金バッグ（緑）、島に 12 個ある隠しパッケージ（水色）。
- **時間と天候**: 昼夜サイクル（1 日 = 12 分）、晴れ / 曇り / 雨 / 霧。雨の日はタイヤが滑ります。夜は街灯と窓明かり、ヘッドライトが点きます。
- **セーブ**: 60 秒ごと・ミッションクリア時・パッケージ取得時に自動セーブ（localStorage）。ポーズ画面から手動セーブも可能。ミッション中・手配中はセーブされません。
