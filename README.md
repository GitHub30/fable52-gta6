# VELA BAY — Open World Sandbox

**▶ ブラウザで遊ぶ: https://github30.github.io/fable52-gta6/**

ブラウザ（Chrome デスクトップ）で動く、オリジナルの 3D オープンワールド・サンドボックスゲームです。
舞台は大阪の**通天閣・新世界〜天王寺・阿倍野**（約 1.6km × 1.4km）。道路・建物の形・標高・航空写真は実際の公開データから作っています。
車・人物・音はコードから生成しています。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー（ポート 5173） |
| `npm run typecheck` | TypeScript 型チェック |
| `npm run build` | 型チェック + 本番ビルド（`dist/`） |
| `npm run preview` | ビルド結果のプレビュー |

## 操作方法

| 操作 | キー |
|---|---|
| 移動 / アクセル・ブレーキ・ハンドル | W A S D |
| カメラ | マウス（クリックでポインターロック。ロックできない環境ではドラッグ） |
| 走る | Shift |
| ジャンプ / ハンドブレーキ（運転中） | Space |
| 車に乗る・降りる（走行中の車は強奪） | E |
| ミッション開始・攻撃（パンチ / 射撃） | F / 左クリック |
| 武器切替（素手 / ピストル / AK-47 / ロケットランチャー） | 1 / 2 / 3 / 4 |
| ヘリコプター: 上昇 / 下降（W A S D で飛行、着陸して E で降りる） | Space / Shift |
| 旅客機: 加速 / 減速、旋回、機首上げ（110km/h 以上で離陸）/ 機首下げ | W / S、A / D、Space / Shift |
| クラクション | H |
| ラジオ ON/OFF（運転中に再生） | R |
| ミッション中止 | M |
| 時間を 1 時間進める / 天候切替 | T / Y |
| 一時停止・操作確認 | ESC / P |

操作一覧はタイトル画面とポーズ画面でも確認できます。

## ゲーム内容

- **マップ**: 通天閣（新世界）、天王寺動物園、てんしば・天王寺公園、一心寺、天王寺駅前、あべのハルカス、阿倍野、四天王寺、新今宮、恵美須町。道路網と建物の輪郭は OpenStreetMap、地面は国土地理院の航空写真、高低差（上町台地の坂。標高差約 27m）は国土地理院の 5m 標高データです。日本なので左側通行です。
- **車**: プリウス風のリフトバックとアルファード風のミニバンの 2 車種（タクシーとパトカーはプリウス型）。ほかに救急車（病院前に 1 台）と消防車（スタート地点の 1 ブロック東に 1 台）があり、街中も走っています。駐車車両にも走行中の車にも乗れます。車にはダメージがあり、壊れると煙が出て動かなくなります。
- **街の動き**: 信号を守って走る一般車両、歩道を歩き横断する歩行者。危険を感じると逃げます。
- **手配度（★1〜5）**: 車両強盗・暴行・ひき逃げ・パトカーへの衝突で上昇。パトカーが追跡し、囲まれて止まると逮捕（BUSTED）。警察の視界から外れ続けると解除されます。
- **戦闘**: 素手、ピストル、AK-47（押しっぱなしで連射）、ロケットランチャー（爆発で車を破壊）。最初から全部持っています（36 発 / 90 発 / 6 発）。オレンジの弾薬箱で弾を補給、赤い救急キットで回復（どちらも 90 秒で再出現）。気の強い通行人は殴り返してきます。
- **タッチ操作（スマホ・タブレット）**: タッチ端末では自動で画面上の操作 UI が出ます。画面の左半分を触るとその位置に移動スティックが現れ、右半分のドラッグで視点を動かします。右下のボタンは状況で変わります（徒歩: 攻撃 / ジャンプ / 乗る / 武器、車: 発砲 / ブレーキ / 降りる / クラクション、ヘリ・旅客機: 上昇 / 下降 / 降りる）。徒歩ではスティックをいっぱいに倒すと走ります。右上の Ⅱ で一時停止。
- **フルスクリーン**: 「ニューゲーム」「つづきから」「再開」を押すと全画面になり、スマホ・タブレットでは横向きに固定します。iPhone の Safari はページの全画面化に対応していないため、共有メニューの「ホーム画面に追加」から起動すると全画面で遊べます。
- **阿倍野歩道橋**: 天王寺駅前・あべのハルカス前の交差点に、実際の平面形（「a」字型）で架かっています。階段から上ってデッキを歩いて渡れます（手すりに当たり判定はないので、端から落ちます）。夜は膜屋根が光ります。
- **チェーン店**: マクドナルド、セブン-イレブン、ファミリーマート、ローソン（ローソンストア100 を含む）が OpenStreetMap 上の実際の位置に建っています（地上階の店舗のみ）。位置データは `python tools/fetch_stores.py` で `public/osaka/stores.json` に焼き込みます。
- **Vietjet A321**: スタート地点そばの広場に駐機（ミニマップの赤い◆）。乗ると `public/music/vietjet.m4a` が機内 BGM として流れ、降りると止まります。機首は離陸できる通りを向いています。失速（約 85km/h 以下）すると沈むので、着陸は速度を保ったまま接地してから S で減速します。
- **ヘリコプター**: ダウンタウン南の公園と南・東のビーチに 1 機ずつ（ミニマップの白い◆）。ビルの屋上にも着陸できますが、降りられるのは地上だけです。壊れると墜落して爆発し、30 秒後に元の場所へ戻ります。
- **徒歩の警官**: ★2 以上で、止まったパトカーから警官が降りて追ってきます。至近距離で逮捕、★3 以上では発砲。倒すと弾を落としますが手配度が上がります。空になったパトカーは奪えます。
- **ミッション（5 種）**: ミニマップのピンクの◆へ徒歩で行き F で開始。配達、チェックポイントレース、逃走、タクシー、木箱回収。クリアで賞金。
- **イベント・収集**: ランダムに出現する現金バッグ（緑）、島に 12 個ある隠しパッケージ（水色）。
- **時間と天候**: 昼夜サイクル（1 日 = 12 分）、晴れ / 曇り / 雨 / 霧。雨の日はタイヤが滑ります。夜は街灯と窓明かり、ヘッドライトが点きます。
- **見た目の限界**: 地面と屋根は航空写真ですが、建物の壁は種類別の生成テクスチャで、実物の外観や看板は再現していません。高さが地図に無い建物は面積から推定しています。高架の線路・高速道路・駅舎の内部はありません。
- **セーブ**: 60 秒ごと・ミッションクリア時・パッケージ取得時に自動セーブ（localStorage）。ポーズ画面から手動セーブも可能。ミッション中・手配中はセーブされません。

## 地図データの出典と作り直し方

- 道路・建物・公園: © OpenStreetMap contributors（ODbL）
- 航空写真・標高: 国土地理院（地理院タイル「シームレス空中写真」「標高タイル（基盤地図情報数値標高モデル）」）

変換済みのデータは `public/osaka/` にあります（`map.json` / `dem.bin` / `ground.jpg` / `far.jpg`）。範囲を変えたり取り直したりする場合:

```bash
python tools/fetch_osaka.py
```

Python 3 と `requests` `numpy` `Pillow` が必要です。ダウンロードした元データは `tools/.cache/` に保存されます。
