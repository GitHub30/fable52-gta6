# アーキテクチャ

## 技術構成

- **TypeScript + Vite + Three.js (WebGL)**。ランタイム依存は `three` のみ。
- **物理エンジンは不使用**。都市が完全な格子で、衝突対象が「軸平行の箱」と「円」だけで足りるため、
  自前の「円 vs AABB（空間ハッシュ）」で実装した。Rapier を入れるより依存とロード時間が減り、
  100 台超の車両を 1 フレーム約 0.2ms でシミュレートできる。坂・ジャンプ台など 3D 物理が必要になったら再検討する。
- **アセットファイルなし**。ジオメトリはコード生成、テクスチャは Canvas、音は WebAudio で合成。

## 世界の座標系

- 都市は `N=12` ブロックの格子。道路中心線 `k`（0..N）の座標は `roadCoord(k) = -HALF + k * PITCH`（`PITCH = BLOCK 60 + ROAD 16`）。
- ブロック内は歩道（縁石高さ `CURB = 0.15`）、それ以外は車道（高さ 0）。`City.groundHeight()` が唯一の地面判定。
- 向き `heading θ` の前方ベクトルは `(sin θ, cos θ)`（x, z）。車もキャラクターも +Z 向きにモデリングしている。
- 右側通行。進行方向 `(dx, dz)` の右は `(-dz, dx)`。走行レーンは道路中心から `LANE = 2.2`、路上駐車は `PARK_OFFSET = 6.6`。
- 都市生成は固定シードの乱数（`mulberry32`）なので毎回同じ街になる（セーブ座標・ミッション座標が有効であり続ける）。

## メインループ（`Game.frame`）

1. 入力（ポーズ切替）
2. `step(dt)`: 乗降・行動 → `Traffic.update`（AI が各車の throttle/steer を決める）→ 全 `Vehicle.update`（物理）→ 車同士の衝突
   → プレイヤー → 歩行者 → 手配度 → ミッション → 環境 → エフェクト → カメラ → 音 → HUD
3. 描画
4. `Input.endFrame()`

`dt` は 0.05 秒で上限をかける。`Game.debugStep(frames)` で同じ `frame()` を任意回数回せる（自動テスト用）。

## 設計方針

- **AI 車もプレイヤー車も同じ `Vehicle` 物理**。違いは誰が `throttle / steer / handbrake` を書くかだけ（`driver: none | player | ai | police`）。
  そのためプレイヤーが AI 車にぶつかれば普通に弾かれ、奪えばそのまま運転できる。
- **交通 AI は格子グラフ上のレーン追従**。区間の「開始点 → 停止線」を先読み点で追い、交差点で次の方向を選ぶ。
  警察は同じ仕組みで「プレイヤーに近づく方向」を選び、見通しが通れば直接追跡に切り替える。
- **描画コール削減**: 建物は全体で 2 メッシュ（壁・屋根）、道路標示・木・街灯・信号は `InstancedMesh`、
  車は 1 台 1 メッシュ（色ごとにジオメトリをキャッシュ）、人は 5 メッシュ。
- **遠方の処理**: 車と歩行者は一定数のプールで、プレイヤーから離れたものを近くに再配置する（無限に増えない）。
  停止中の無人車は物理をスキップする。遠い歩行者はアニメーションを止め、非表示にする。
- **影**: 太陽の影カメラはプレイヤー周囲 150m 四方だけを覆い、2m 単位でスナップさせてちらつきを抑える。
- **適応解像度**: フォーカス中に 27fps 未満が続くとピクセル比を段階的に下げる。
- **夜の表現**: 窓明かりは emissiveMap、街灯の光だまりは加算合成の板、車のランプは 1 を超える頂点カラー。動的ライトはプレイヤー車のヘッドライト 1 灯のみ。

## 拡張するときの入口

| やりたいこと | 触る場所 |
|---|---|
| ミッション追加 | `Missions.ts` の `defs` に 1 件追加（`goto` / `evade` の目標列） |
| 車種追加 | `Vehicle.ts` の `SPECS` と、車体形状を返す `priusParts` / `alphardParts` のような関数 |
| 地区・建物の見た目 | `City.ts` の地区判定とブロック生成 |
| 新しい犯罪・手配ルール | `Game.ts` の該当イベントから `wanted.crime(min, cap, 理由)` |
| 武器追加 | `Game.ts` の `shoot()`（ヒットスキャンと照準補正）と `weapon` の種類 |
| 補給アイテムの配置 | `Missions.ts` コンストラクタの `place('ammo' / 'health', ...)` |
| 天候追加 | `Environment.ts` の `Weather` と各ブレンド係数 |
