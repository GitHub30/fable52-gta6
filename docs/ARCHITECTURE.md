# アーキテクチャ

## 技術構成

- **TypeScript + Vite + Three.js (WebGL)**。ランタイム依存は `three` のみ。
- **物理エンジンは不使用**。衝突対象が「建物の輪郭（多角形）」と「円」だけで足りるため、
  自前の「円 vs 多角形（空間ハッシュ）」で実装した。100 台超の車両を 1 フレーム約 0.3ms でシミュレートできる。
- **地図は実データ**。`tools/fetch_osaka.py` が OpenStreetMap と国土地理院タイルを取得・変換して `public/osaka/` に置く。
  車・人物・建物の壁テクスチャ・音はコード生成（Canvas / WebAudio）。

## 世界の座標系と地図データ

- 単位はメートル。原点は範囲の中心（北緯 34.64975°, 東経 135.5095°）。**x = 東、z = 南**（北が -Z）、y = 最低地点からの高さ。
- 向き `heading θ` の前方ベクトルは `(sin θ, cos θ)`（x, z）。車もキャラクターも +Z 向きにモデリングしている。
- **標高**: 4m 間隔の格子（`dem.bin`、cm 単位）。`City.groundHeight()` が双一次補間で返す唯一の地面判定。
  橋の区間は変換時に両端の高さで均して盛り土にしている（測量データでは橋の下の掘割が写るため）。
- **道路**: OSM の way を交差点で分割したグラフ。`Edge` は種別 `k`（0 幹線〜4 生活道路、5 歩行者道路、6 歩道）、幅、一方通行、
  `car`（車が走れる）、`ai`（一般車両が走る。三級道路以上）を持つ。
- **左側通行**。進行方向 `(dx, dz)` の左は `(dz, -dx)`。対面通行の道では中心線から幅の 1/4 だけ左に寄せた線（`City.lane()`）を走る。
- **建物**: OSM の輪郭を反時計回りにそろえ、`height` / `building:levels` があればその高さ、無ければ面積から推定。
  車道に重なる輪郭（駅のデッキなど）は変換時に取り除く。
- **ランドマーク**: あべのハルカスは実輪郭を 3 段に絞った 300m のガラスの塔、通天閣は専用モデル（脚の間を車が通れる）。
- 場所の座標は `City.ts` の `PLACES`。ミッション・補給・スポーン・地区名はここから `roadSpot()` / `sideSpot()` で道路上の点に寄せる。

## メインループ（`Game.frame`）

1. 入力（ポーズ切替）
2. `step(dt)`: 乗降・行動 → `Traffic.update`（AI が各車の throttle/steer を決める）→ 全 `Vehicle.update`（物理）→ 車同士の衝突
   → プレイヤー → 歩行者 → 手配度 → ミッション → 環境 → エフェクト → カメラ → 音 → HUD
3. 描画
4. `Input.endFrame()`

`dt` は 0.05 秒で上限をかける。`Game.debugStep(frames)` で同じ `frame()` を任意回数回せる（自動テスト用）。

## 設計方針

- **AI 車もプレイヤー車も同じ `Vehicle` 物理**。違いは誰が `throttle / steer / handbrake` を書くかだけ（`driver: none | player | ai | police`）。
  そのためプレイヤーが AI 車にぶつかれば普通に弾かれ、奪えばそのまま運転できる。
- **交通 AI は道路グラフ上のレーン追従**。レーンの点列を順に追い、区間の終点で次の区間を選ぶ（直進寄りの乱択）。
  信号は無く、交差点では先に近づいた交差方向の車に道を譲る。警察は同じ仕組みで「プレイヤーに近づく区間」を選び、見通しが通れば直接追跡に切り替える。
- **描画コール削減**: 建物は壁 4 種 + 屋根の 5 メッシュ（屋根には航空写真を投影）、道路は種別ごとに 1 メッシュ、木・街灯は `InstancedMesh`、
  車は 1 台 1 メッシュ（色ごとにジオメトリをキャッシュ）、人は 5 メッシュ。
- **遠方の処理**: 車と歩行者は一定数のプールで、プレイヤーから離れたものを近くに再配置する（無限に増えない）。
  停止中の無人車は物理をスキップする。遠い歩行者はアニメーションを止め、非表示にする。
- **影**: 太陽の影カメラはプレイヤー周囲 150m 四方だけを覆い、2m 単位でスナップさせてちらつきを抑える。
- **適応解像度**: フォーカス中に 27fps 未満が続くとピクセル比を段階的に下げる。
- **夜の表現**: 窓明かりは emissiveMap、街灯の光だまりは加算合成の板、車のランプは 1 を超える頂点カラー。動的ライトはプレイヤー車のヘッドライト 1 灯のみ。

## 拡張するときの入口

| やりたいこと | 触る場所 |
|---|---|
| ミッション追加 | `Missions.ts` の `defs` に 1 件追加（`goto` / `evade` の目標列。場所は `PLACES` から） |
| マップの範囲変更 | `tools/fetch_osaka.py` の `S, W, N, E` を変えて再実行し、`City.ts` の `PLACES` を合わせる |
| 車種追加 | `Vehicle.ts` の `SPECS` と、車体形状を返す `priusParts` / `alphardParts` のような関数 |
| 建物の見た目 | `City.ts` の `facade()`（壁テクスチャ 4 種）と建物ループの種別・色の選び方 |
| 新しい犯罪・手配ルール | `Game.ts` の該当イベントから `wanted.crime(min, cap, 理由)` |
| 武器追加 | `Game.ts` の `GUNS`（連射間隔・ダメージ・拡散）と `PROPS`（手に持つモデル）。弾丸は `shoot()`、ロケットは `fireRocket()` と `explode()` |
| 補給アイテムの配置 | `Missions.ts` コンストラクタの `place('ammo' / 'health', ...)` |
| 天候追加 | `Environment.ts` の `Weather` と各ブレンド係数 |
